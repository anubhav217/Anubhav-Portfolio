# Anubhav Majumdar — Portfolio

This project is a polished React portfolio with Framer Motion animations and Typewriter effect.

## Quick start (locally)
1. Ensure Node.js (16 or 18 recommended) & npm are installed.
2. From project root:
   npm install
   npm start
Open http://localhost:3000

## Build & Deploy
1. npm run build
2. npm run deploy
